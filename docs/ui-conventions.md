# 界面约定

## 二选一控件

二选一控件切换后直接应用，不另外点「应用」。选择形态时，先看改变的是什么，不看画面当场变不变。

- **滑动开关**管一项独立的效果或处理，有或没有。它是作品的一部分，会影响导出，Ctrl+Z 可以撤销。标签是这项效果或处理的名称，不随状态变；开关在标题行末，关掉时收起它控制的滑杆，状态另用下方小字说明。
- **勾选框**管查看和工具，不是作品的一部分。标签用名词或短语。查看选项跟在「显示」后，或做一组查看内容的组头（如「标出问题」）；工具选项放在工具自己的浮条里。点选范围还显示着刚才那次加选时，切换「补细缝」会按新选择重做那次点选。
- **数值旁的按下态小按钮**决定数值由谁来定，和数值一起保存、一起撤销。写方式的名字（「自动」「自动 100%」等），紧贴数值的标题行，按下时用浅底深字。联动两个数值时可用夹在两者之间的括号按钮，例如「关联」用实线表示关联、虚线表示不关联。

## 保存位置

| 归哪一层 | 什么时候用 | 怎么记 |
| --- | --- | --- |
| **纹理设置** | 换一张图也适用的外观设置，例如纹理层、纹理减弱。 | 随当前工作恢复，能存进预设；可以撤销，「全部恢复默认」会重置。 |
| **只跟这张图** | 取决于这张图的部位或颜色，例如颜色排除。 | 随当前工作恢复，不进预设；颜色排除可以撤销，「全部恢复默认」不动它。 |
| **这台电脑上的习惯** | 定一次就一直适用，例如语言、界面大小或工具怎么帮忙。 | 记在本机；换图、重开都保留，不进预设，也不随作品撤销。 |
| **本次打开期间** | 临时想看什么，例如「显示」后的勾选项和「标出问题」。 | 只在打开的页面里保留，同次打开期间换图不变；重载或重开恢复默认，不进预设，也不随作品撤销。 |

前两层的「当前工作」指自动保存的那一份，不是按原图文件各存一份。换了图再打开原文件是新工作；要复用纹理设置，用预设，要带回部位和走向线，导出丝袜引导 PSD。

位置不决定保存范围。「标出问题」那一组把相关内容放在一起，但纹理减弱进预设，颜色排除不进；保存时要说明带什么、不带什么。另一个特例是「自动 100%」：当前值随纹理设置保存和撤销，但亲手切换它也会记下新图的起步值；读取预设和撤销不改这个起步值。

要跨会话记住的工具偏好放在应用的用户设置文件，不用浏览器的 `localStorage`；端口变了，浏览器会把它当成另一个来源。
