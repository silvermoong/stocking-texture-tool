# 走向线只定方向，不定疏密

横纹的坐标场以梯度为 1 为目标求解（结果约等于 1），所以走向线只决定横纹往哪走，间距由密度滑杆决定，在屏幕上大致等距（`stocking/guide_fields.py` 开头说明，README「线只管方向，不管疏密」）。这是有意偏离参考实现：参考实现里走向线挤在一起表示透视，会被带进坐标场，让那里的横纹变密（`.scratch/stocking-texture-tool/spec.md` 的 period 一条）。

改成只定方向的具体原因，仓库里没有写明（未知），见 `docs/agents/open-questions.md`。

## Consequences

- 走向线画得密还是稀结果一样；画面里的透视缩短不会自动让横纹变密。
- 密度 100% 的横纹间距按图片面积换算，同样的屏幕大小看起来一样；太密时由减弱处理，而不是由走向线控制。
