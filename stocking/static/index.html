    纹理层试验

    每一层都按同一套走向线画，再按各层的融合比例合在一起。

    点层的名字，下面框里的样式、密度、斜度和强度就切到那一层。

    亮点、高光粒子、摩尔纹效果在融合之后统一加，不在每层里重复算。

      每层各调各的

      样式

      斜单线相对横纹的倾斜程度：0° 就是顺着横纹走；数值越大，线越斜。

      两条腿往相反的方向斜，左右对称成人字形：名字里带“左”“右”的部位按名字分边，其他部位按在画面里的位置分，画面左边的算左；夹在两边中间的（比如胯部）不斜。

      下面的设置各层共用，对整张图生效

      纱线反光形成的细小闪光点，撒在丝袜受光的地方。默认关，打开开关才有，下面的滑杆决定撒在哪、撒多少。

      按深度：放在鼓起来的地方，比如膝盖、腿正面、胸顶。

      按画面亮部：放在画师画出来的高光上。

      关联：打开时这两个数量保持一样，拖其中一个，另一个跟着变。

      均匀分布：整只丝袜上到处都撒，不挑位置，适合亮片丝、闪光丝。

      有浅色印花或条纹的丝袜，把画面亮部调低，免得亮点落在印花上。

      想自己决定位置：在 PSD 的“丝袜引导”组里画一层叫“亮点”的图层，再打开那个 PSD，这里会多一个滑杆。

      像油光那样顺着画面里的受光处找出高光带（深色丝袜上同样会延续到整条腿），但把高光画成细密的粒子，中间密、往两侧渐渐散开。默认关，打开开关才有，可以叠加在任何样式上。

      亮度：高光粒子有多亮、多明显。

      给丝袜加上一圈圈水波似的明暗条纹，像现实里的丝袜叠穿、拍照时出现的摩尔纹。默认关，打开开关才有。

      明暗：条纹的明暗差别有多大。

      面积：从每个鼓起处顶上的一小圈开始，一圈圈往外扩，环数也跟着变多；拉满就是整个鼓起的地方都有。

      条纹顺着身体鼓起的地方走：膝盖、大腿、胸顶各围成一圈圈，平的地方没有。位置由深度模型估出的起伏决定，鼓得越高，环越多。

      这是特意加上的效果。纹理本身不会出摩尔纹，这一点不变；关掉开关，效果就没了。

      隔开：沿两块丝袜的交界画一条线，松开鼠标就画好了

        细节

        空格按住看这里的原图

        打开时，横纹挤得太近、间距接近像素大小的地方会自动把纹理减弱，避免挤出细碎的摩尔纹。

        关掉后，无论横纹多密都照常画满纹理。勾上“标出问题”，可以看到哪里被减弱了（红色）；降低密度可以减少这一块，有几层纹理时降横纹最密的那一层。

        打开时，部位里颜色和丝袜差得远的地方不加纹理，比如金边、手套、露出来的皮肤。

        薄丝袜透出肤色的地方（膝盖、脚尖）偏暖，有时会被误当成皮肤排除掉。这时关掉它，就不再按颜色排除。勾上“标出问题”，可以看到哪里被排除了（蓝色）。

        没有走向线

        部位已经涂好，但不生成纹理的地方：部位没有走向线、求解失败，或部位里分开的一块没有走向线。回“引导”页检查它们的走向线。

        快捷键与手势

        空格在两页的用途

        引导
        按住空格拖动画面。
        纹理
        按住空格查看细节原图，松开恢复效果。

        键盘聚焦的控件自己用空格。先把焦点移到画面（可用「跳到画面」）或细节。

        通用操作

        Ctrl+O 拖入文件
        打开图片或 PSD
        Ctrl+E
        按顶栏主按钮的当前方式导出
        Ctrl+Z
        撤销当前页的上一步
        Ctrl+Shift+Z Ctrl+Y
        重做当前页的一步
        ? Esc
        用问号打开或关闭速查表，也可按 Esc 或点弹窗外关闭。
        Tab Shift+Tab
        聚焦下一个或上一个控件
        Enter 空格
        激活用键盘聚焦的按钮
        ← ↑ ↓ → Home End
        在页签或单选组中切换；Home / End 选首项或末项。
        菜单内
        ↑ / ↓ 切换项目，Esc 或 Tab 退出。→ 进入「合并到」，← 或 Esc 返回上一级。

        文件与撤销重做的 Ctrl 组合键也可用 Command。

        纹理页预览

        点击整体
        把细节预览移到点击处
        拖动对比拖杆
        整体预览左边显示原图，右边显示效果。
        ← → Home End
        对比拖杆有焦点时，左右键移动拖杆，加按 Shift 移得更远；Home 全看效果，End 全看原图。
        拖动细节
        平移查看的位置；细节有焦点时也可用方向键，加按 Shift 移得更远。
        空格
        用 Tab 聚焦到“标出问题”或它那一组的开关时，空格切换它；用鼠标点过之后，空格仍是按住看细节原图。
        Delete
        纹理层名有焦点时删除该层

        引导页工具

        W
        点选：左键加进当前部位，右键减去。
        Tab Shift+Tab
        点选后，画面有焦点时，向前或向后切换小 / 中 / 大范围。
        悬停或单击 小 / 中 / 大
        点选后，悬停高亮该范围的轮廓，单击直接选这一档。
        B
        画笔：左键拖动涂抹，右键拖动擦除。
        E
        橡皮：用左键或右键拖动擦除当前部位。
        K
        切开：左键拖线分割当前部位。
        Esc
        切开时取消正在画的线；没在画线时回到上一工具。
        P
        走向：左键拖动画走向线。
        D
        隔开：左键沿交界拖动画隔开线。
        Delete Backspace 右键单击
        用走向或隔开工具时，删除指针下的相应线。
        [ ]
        缩小或放大笔刷
        ↑ ↓
        部位列表有焦点时切换部位
        F2 双击部位名
        给部位改名（F2 要先聚焦列表）；Enter 确认，Esc 取消。
